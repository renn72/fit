# Create Menu Templates

Menu templates define the reusable structure you will assign to users.

## Where in the app

- Menu templates list: `/$orgSlug/menu-templates`
- Create template: `/$orgSlug/menu-templates/create`
- Edit template: `/$orgSlug/menu-templates/edit/$menuId`

## Steps

1. Open **Menu Templates**.
2. Click **Create Menu Template**.
3. In the template form:
   - set template name and description
   - add meals
   - add recipes into each meal
   - adjust targets and ingredient amounts as needed
4. Save the template.

## Tips

- Build templates around delivery models (for example `5-Day Fat Loss`, `7-Day Performance`).
- Keep recipe ordering consistent by meal and day structure.
- Use template edits to improve all future user assignments without rebuilding from scratch.

## Next Step

After templates are saved, continue to [Assign Menu Template to User](/guides/user-menu-system/assign-menu-template-to-user/).
