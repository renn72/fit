# Create Recipes

Recipes combine ingredients into reusable meal components for templates and user menus.

## Where in the app

- Recipes list: `/$orgSlug/recipes`
- Create recipe: `/$orgSlug/recipes/create`
- Edit recipe: `/$orgSlug/recipes/edit/$recipeId`

## Steps

1. Open **Recipes**.
2. Click **Create Recipe**.
3. Enter recipe details:
   - name
   - description
   - category tags
   - meta tags (if used in your org workflow)
4. Add ingredients from your organisation ingredient library.
5. Set amounts and units for each ingredient.
6. Save the recipe.

## Tips

- Make recipe names unique and specific so template builders can find them quickly.
- Reuse ingredients instead of creating near-duplicates.
- If AI recipe support is enabled, you can use the recipe form AI section to speed up drafting.

## Next Step

Once recipes are ready, continue to [Create Menu Templates](/guides/user-menu-system/create-menu-templates/).
