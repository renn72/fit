# Assign Menu Template to User

This is the final delivery step: take a template and assign it to a user menu.

## Where in the app

- User menus list: `/$orgSlug/user-menus`
- Create user menu: `/$orgSlug/user-menu-create`
- Edit user menu: `/$orgSlug/user-menu-edit/$menuId`

## Steps

1. Open **Create User Menu**.
2. Select the target user.
3. Choose a template (or start from blank).
4. Review and adjust:
   - menu details
   - meal structure
   - recipe selection
   - ingredient amounts and targets
5. Save the menu.
6. Confirm the result in **User Menus**.

## Tips

- Use templates as the starting point, then personalize only what is needed.
- Confirm date ranges and meal naming before saving.
- For edits, use the user menu edit screen to maintain delivery history while updating content.
