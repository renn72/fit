# User Menu Workflow Overview

This guide set documents the full workflow used in Forma to build and deliver nutrition menus to users.

## System Flow

1. [Create Ingredients](/guides/user-menu-system/create-ingredients/)
2. [Create Recipes](/guides/user-menu-system/create-recipes/)
3. [Create Menu Templates](/guides/user-menu-system/create-menu-templates/)
4. [Assign Menu Template to User](/guides/user-menu-system/assign-menu-template-to-user/)

## Why this order matters

- Ingredients create a single nutrition source of truth.
- Recipes provide reusable meal components.
- Templates standardize delivery quality and speed.
- User assignment personalizes output without rebuilding from scratch.

## Related Product Context

Forma is a trainer-first coaching operating system that combines programming, nutrition, tracking, check-ins, and AI-assisted workflows for teams and high-performance environments.
