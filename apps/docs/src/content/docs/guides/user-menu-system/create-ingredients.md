# Create Ingredients

Ingredients are the base layer for everything else in the user menu system.

## Where in the app

- Ingredients list: `/$orgSlug/ingredients`
- Create ingredient: `/$orgSlug/ingredients/create`
- Edit ingredient: `/$orgSlug/ingredients/edit/$ingredientId`

## Steps

1. Open **Ingredients**.
2. Click **Create Ingredient**.
3. Fill out:
   - name
   - category tags
   - calories, protein, fat, carbohydrate
   - serve size and serve unit
4. Save the ingredient.
5. Repeat until your common food items are in place.

## Tips

- Keep naming consistent (for example `Chicken Breast, Raw` vs `Chicken Breast, Cooked`).
- Use category tags so recipe builders can filter quickly.
- Validate macro values against your source database before publishing.

## Next Step

After ingredients are in place, continue to [Create Recipes](/guides/user-menu-system/create-recipes/).
