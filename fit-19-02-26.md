### Database Schema Consolidation
- **Merged base tables into main tables** following the architectural decision to simplify the data model:

## Summary
The consolidation eliminates the dual-table pattern in favor of a single-table design with discriminating boolean flags. This simplifies queries, reduces join complexity, and makes the data model more intuitive while maintaining the ability to track base item overrides.

Route refactoring provides cleaner, shorter URLs that are more user-friendly and easier to share. The `/admin/s` prefix was unnecessarily verbose.
