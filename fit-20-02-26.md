## Tasks

### Session → Workout Rename
- **Renamed `session` table to `workout`** to resolve naming collision with Better Auth's `session` table
- **Schema changes** (`packages/db/src/schema/workout.ts`):
  - Table `session` → `workout`
  - Table `session_to_exercise` → `workout_to_exercise`
  - Table `session_to_superset` → `workout_to_superset`
  - Column `sessionId` → `workoutId` in all junction tables
  - Index names updated: `session_*` → `workout_*`

- **Relations updates** (`packages/db/src/relations.ts`):
  - Updated all relation references from `session` to `workout`
  - Updated junction table relations: `sessionToExercise` → `workoutToExercise`, `sessionToSuperSet` → `workoutToSuperSet`
  - Added `workouts` relation to user and organisation

- **API changes** (`packages/api/src/routers/workout.ts`, `packages/api/src/schemas/workout.ts`):
  - Renamed all schemas: `SessionXxxInput` → `WorkoutXxxInput`
  - Renamed router: `sessionRouter` → `workoutRouter`
  - Updated all paths: `/session/*` → `/workout/*`
  - Updated tags: `'Session'` → `'Workout'`

- **Router registration** (`packages/api/src/routers/index.ts`):
  - Updated import and key from `session` to `workout`

- **Deleted old files**:
  - `packages/db/src/schema/session.ts`
  - `packages/api/src/schemas/session.ts`
  - `packages/api/src/routers/session.ts`

- **Database migration required** to rename tables in database

### Warmup Group Management Interface
- **New API endpoint** (`packages/api/src/routers/warmup.ts`):
  - Added `createGroupWithWarmups` procedure (POST `/warmup/group/with-warmups`)
  - Creates warmup group and all warmups in a single transaction
  - Requires at least 1 warmup (enforced by schema)

- **New schemas** (`packages/api/src/schemas/warmup.ts`):
  - `WarmupItemInput` - Individual warmup schema
  - `WarmupGroupWithWarmupsCreateInput` - Combined group + warmups schema

- **New route** (`apps/web/src/routes/$orgSlug/warmups.tsx`):
  - Route at `/$orgSlug/warmups`
  - Prefetches warmup groups data
  - Uses `ssr: false` for client-side rendering

- **New components**:
  - `apps/web/src/components/admin/warmups-table.tsx` - DataTable for warmup groups
    - Columns: Name, Description, Warmup Count, Creator, Created At
    - Client-side pagination and sorting
    - "Add Warmup Group" button
  
  - `apps/web/src/components/admin/warmup-group-create-dialog.tsx` - Dialog wrapper
    - Shadcn Dialog with trigger button
    - Integrates create form
  
  - `apps/web/src/components/admin/warmup-group-create-form.tsx` - Form component
    - Group fields: Name (required), Description
    - Dynamic warmup list with "Add Warmup" button
    - Each warmup: Name (required), Description, Image URL, Video Link
    - Remove button on each warmup (minimum 1 enforced)
    - Uses TanStack Form with Zod validation

- **Sidebar update** (`apps/web/src/components/admin-sidebar/app-sidebar.tsx`):
  - Added "Warmups" link under Fitness section
