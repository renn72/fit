### Menu Templates System (Nutrition)
- **Database Schema** (`packages/db/src/schema/menu-template.ts`):
  - `menu_template` table with: id, name, description, category, creatorId, organisationId, timestamps
  - `menu_template_to_recipe` junction table with dual indexes:
    - `mealIndex` - which meal slot (0, 1, 2, etc.)
    - `recipeIndex` - order within that meal (0, 1, etc.)
  - Example: mealIndex=2, recipeIndex=1 means "2nd recipe in meal 3"
  - Unique constraint on (menuTemplateId, mealIndex, recipeIndex) combination

- **Relations** (`packages/db/src/relations.ts`):
  - Added `menuTemplate` relations (creator, organisation, recipes)
  - Added `menuTemplateToRecipe` relations (menuTemplate, recipe)
  - Extended `recipe` with `menuTemplates` relation
  - Fixed duplicate recipe key issue

- **API Layer** (`packages/api/src/routers/menu-template.ts`):
  - Full CRUD operations:
    - `getAll` - Dictator only, all menu templates across orgs with creator/organisation details
    - `getAllOrg` - Get all menu templates for an organisation with full recipe details
    - `get` - Get single menu template with recipes ordered by mealIndex/recipeIndex
    - `create` - Create new menu template (requires itemUpdater or dictator)
    - `update` - Update menu template
    - `delete` - Delete menu template
    - `addRecipe` - Add recipe to menu template with mealIndex and recipeIndex
    - `removeRecipe` - Remove recipe from menu template

- **Schemas** (`packages/api/src/schemas/menu-template.ts`):
  - Input validation schemas for all operations
  - Dual index support: mealIndex + recipeIndex

- **Frontend Components**:
  - **`menu-templates-page.tsx`** - Main page with:
    - **Table View**: Columns for Name, Description, Category, Recipe Count (with meal count), Creator, Created At
    - **Grid View**: Cards showing:

      - Stats (recipe count, meal count)
      - **Meal Schedule** organized by mealIndex:
        - Each meal shows meal number (e.g., "Meal 1")
        - Recipes within each meal showing name and category
        - Cooking pot icon for meals, fork/knife icon for recipes
      - Scrollable meal area
  
  - **`menu-templates.tsx`** route at `/$orgSlug/menu-templates`
